# GoTunnel 🚀
تانل TCP سریع، پایدار و بهینه — نوشته شده با Go

## ویژگی‌ها

- ✅ **Pool اتصال** — تانل‌ها قبل از رسیدن کاربر آماده‌ان، هیچ تأخیری نیست
- ✅ **Reconnect خودکار** — اگه اتصال قطع شد، بلافاصله دوباره وصل میشه
- ✅ **Heartbeat** — هر چند ثانیه یکبار سلامت اتصال چک میشه
- ✅ **مصرف حجم بهینه** — فقط ترافیک واقعی کاربر رد میشه
- ✅ **نصب تک‌دستوری** — همه چیز با یک اسکریپت راه‌اندازی میشه
- ✅ **systemd** — بعد از reboot سرور هم خودکار میاد بالا
- ✅ **احراز هویت** — توکن امنیتی برای جلوگیری از دسترسی غیرمجاز

## معماری

```
کاربر
  │
  ▼
سرور ایران (server mode)
  │  پورت کاربری: مثلاً 443
  │  پورت کنترل: مثلاً 8443
  │
  │◄──── تانل TCP (Pool آماده) ────►│
  │
سرور خارج (client mode)
  │
  ▼
xray / v2ray / پنل
(روی همین سرور اجرا میشه)
```

**جریان ترافیک:**
1. سرور خارج چند اتصال تانل از پیش باز میکنه به سرور ایران
2. وقتی کاربر وصل میشه، سرور ایران یکی از این تانل‌های آماده رو استفاده میکنه
3. ترافیک کاربر از طریق تانل به xray/v2ray روی سرور خارج میرسه

---

## پیش‌نیازها

- دو سرور با Ubuntu یا Debian (یکی ایران، یکی خارج)
- دسترسی root به هر دو سرور
- اتصال اینترنت روی هر دو سرور

## نصب

### روش سریع (پیشنهادی)

فقط یک دستور روی هر سرور اجرا کن — اسکریپت همه چیز رو میپرسه:

```bash
git clone https://github.com/Mr6yn/GoTunnel.git
cd gotunnel
chmod +x install.sh
sudo bash install.sh
```

اسکریپت از تو میپرسه:
1. **این سرور ایرانه یا خارج؟**
2. **IP سرور طرف مقابل چیه؟** (فقط برای سرور خارج)
3. **پورت کنترل چنده؟** (پیشفرض 8443)
4. **پورت(های) کاربری چنده؟** (فقط برای سرور ایران، مثلاً 443,80)
5. **توکن امنیتی چیه؟** (باید روی هر دو سرور یکی باشه)

بعد از جواب دادن، همه چیز نصب و اجرا میشه.

## مرحله بعد از نصب تانل

بعد از اینکه تانل روی هر دو سرور نصب شد، نوبت نصب پنل روی **سرور خارج** است.

### نصب 3x-ui

```bash
bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh)
```

بعد از نصب، وارد پنل شو و inbound بساز. پورت inbound رو همون پورتی بذار که موقع نصب GoTunnel به عنوان "پورت سرویس محلی" وارد کردی (پیشفرض 10000).

### نصب Marzban

```bash
sudo bash -c "$(curl -sL https://github.com/Gozargah/Marzban-scripts/raw/master/marzban.sh)" @ install
```

## دستورات مدیریت

```bash
# وضعیت سرویس
systemctl status gotunnel

# لاگ زنده (برای دیباگ)
journalctl -u gotunnel -f

# ریستارت
systemctl restart gotunnel

# استاپ
systemctl stop gotunnel

# حذف کامل
systemctl stop gotunnel
systemctl disable gotunnel
rm /etc/systemd/system/gotunnel.service
rm -rf /opt/gotunnel
```

## رفع مشکلات رایج

**تانل وصل نمیشه:**
```bash
# چک کن پورت کنترل باز باشه (روی سرور ایران)
ufw allow 8443
ufw status

# از سرور خارج تست کن
telnet IP_IRAN 8443
```

**قطع وصلی دارد:**
- فایل `/opt/gotunnel/config.json` رو باز کن
- مقدار `heartbeat_sec` رو کم کن (مثلاً 5)
- مقدار `pool_size` رو بیشتر کن (مثلاً 16)
- بعد `systemctl restart gotunnel` بزن

**لاگ چک کن:**
```bash
journalctl -u gotunnel -f
```
اگه `Heartbeat OK` میبینی یعنی تانل سالمه.
